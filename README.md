# 🛡️ VeritasLens AI
### GenAI-Powered Multimodal Synthetic Media Forensic & Verification Intelligence Platform
*Built for PromptWars x µLearn SJCET Hackathon • Google for Developers "Build with AI"*

---

## 🌟 Executive Overview
**VeritasLens AI** empowers journalists, fact-checkers, intelligence researchers, and everyday citizens to **detect, explain, and verify** AI-generated or manipulated images, audio voice clones, deepfake videos, and viral claims before they are trusted or forwarded across social networks.

---

## 🚀 Key Features & Capabilities

### 1. 🔬 Multimodal Neural Forensics
- **Image Diffusion Detection**: Error Level Analysis (ELA), latent spatial noise distribution, anatomical coherence analysis (digits, corneal reflections), and frequency high-band scanning.
- **Audio Voice Clone & Neural TTS**: 16.2kHz/24kHz spectral ceiling cutoff detection, robotic glottal micro-jitter regularity (<0.05%), and synthetic breath absence.
- **Video Deepfake & Lip-Sync**: Temporal boundary flickering analysis, PERCLOS eye-blink rate monitoring, and phoneme-viseme desynchronization tracking.
- **Viral Claim & News Corroboration**: Cross-referencing claims against Reuters, AP, AFP FactCheck, Snopes, and global OSINT registries.

### 2. 🛡️ Dual-Perspective Experience
- **Citizen Mode (Fast Shield)**: Plain-language explanations ("Why this is fake"), 0-100% Authenticity Score, clear red-flag bullet points, and social sharing advice ("Safe to Forward?").
- **Forensic Mode (Investigative Deep-Dive)**: Interactive Error Level Analysis (ELA) canvas with real-time amplification slider, Noise variance view, Audio Fourier Transform Spectrogram, Frame-by-Frame Video Anomaly Scrubber, EXIF Telemetry, and Cryptographic C2PA provenance credentials.

### 3. ⚡ Interactive Live Demonstrations (Judge-Ready)
- **1-Click Benchmark Arsenal**: Instant testing with high-profile real-world cases (Pope Francis in Balenciaga Puffer Coat, Pentagon Explosion Hoax, CEO Emergency Wire Transfer Voice Clone, State Official Deepfake Video, and Verified Authentic Controls).
- **Live Stream Deepfake Shield HUD**: Real-time webcam and audio biometric monitor with an interactive "Inject Deepfake Attack" button to demonstrate live threat detection.
- **Social Media Share Shield Simulator**: Shows how browser extensions warn users on Twitter/X feeds and WhatsApp group chats before forwarding synthetic media.
- **Truth Academy (Edu Hub)**: Interactive masterclasses on spotting AI artifacts (hands, corneal reflections, vocoder cutoffs, C2PA chains).
- **Exportable Certified Forensic PDF Dossier**: Print or save official forensic reports complete with cryptographic checksums and verification QR codes.

## 🛠️ Architecture & Tech Stack
- **Frontend**: React 18, Vite, Canvas 2D/WebGL Forensic Rendering, Web Audio API, Lucide Icons, jsPDF & html2canvas.
- **Backend**: Node.js, Express REST API, Multer media ingestion, Fourier & ELA simulation engines, OSINT and C2PA trust chain validators.
- **Design Language**: Cyber-Forensic Obsidian Dark Theme (`#07090E`), Electric Cyan (`#06B6D4`), Emerald Safe (`#10B981`), Crimson Alert (`#EF4444`).

## ⚡ Quick Start

### 1. Launch Platform
From the root directory:
```bash
npm start
```
Or start server and client independently:
```bash
# Terminal 1 (Backend API on http://localhost:3001)
npm run server

# Terminal 2 (Vite Frontend on http://localhost:5173)
npm run client
```

### 2. Open in Browser
Visit **`http://localhost:5173`** to access the complete VeritasLens AI platform!
